# Contributing to tpt-benchmark

Contributions are welcome through **issues only**.

- **Bug reports:** open an issue using the bug report template. Include a minimal
  reproduction, your Rust version, and your OS and CPU.
- **Feature requests and questions:** open an issue using the feature request
  template, or a plain issue if neither fits.

Pull requests are not accepted at this time. Describe the change you would like
in an issue, and the maintainers will decide how to implement it.
